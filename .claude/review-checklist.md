# 리뷰 체크리스트 (레포 전용)

`pr-review` 스킬로 기본 검수를 한 뒤, 이 레포에서만 필요한 항목을 추가로 확인합니다. 해당 없는 항목은 건너뜁니다.

## 규칙

- PR 제목 `[파트] [유형] 작업 내용`, 본문 `Closes #이슈번호`, 브랜치 `유형/이슈번호-파트-설명`
- 이슈 범위 밖 파일을 고쳤다면 이유가 PR에 적혀 있는지
- 여럿이 같이 고치는 파일(`package.json`, 잠금 파일, `app.json`, DB 마이그레이션)이 다른 작업과 섞여 있지 않은지

## 앱 (Expo · React Native)

- 새 패키지가 `npx expo install`로 SDK 57에 맞는 버전으로 들어갔는지
- 폰 전용 기능(알람 · 알림 · 네이티브 모듈)을 웹에서 부르면 깨지므로 `.web.ts` 대체 파일이나 `Platform` 분기가 있는지
- 네이티브 모듈 · 플러그인 · `app.json` · 네이티브 패키지 변경이면 "APK 다시 받기 필요"가 PR에 적혀 있는지
- 새 권한(permissions)에 필요한 이유가 있는지
- 화면을 바꾼 PR에 캡처가 있는지

## 데이터 · 서버 (Supabase)

- 스키마 변경은 마이그레이션 파일로만 했는지
- 새 테이블에 RLS가 켜져 있고 정책이 있는지
- `service_role` 키나 외부 API 키가 앱 코드 · `EXPO_PUBLIC_` 변수에 들어가지 않았는지
- 테이블 · 칼럼 이름이 설계 문서와 같은지 (설계 문서가 레포에 있을 때)

## 알람

- 기상 시각 역산 · 알람 강도처럼 시각을 계산하는 로직이 바뀌었으면 테스트가 있는지
- 시간대(Asia/Seoul), 자정 넘김, 반복 알람, 미루기 횟수 처리
