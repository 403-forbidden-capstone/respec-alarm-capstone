# 팀원 카드

Claude에게 "나는 누구고 무엇을 맡았는지"를 알려 주는 파일입니다. 두 가지를 씁니다.

| 파일 | 레포에 올라감 | 내용 |
|---|:-:|---|
| `.claude/team/<이름>.md` (카드) | 올라감 | 역할 · 맡은 기능 · 담당 영역처럼 잘 안 바뀌는 것 |
| `CLAUDE.local.md` (레포 맨 위) | 안 올라감 | 내 카드 불러오기 + 지금 하는 일 + 내 Claude 취향 |

카드는 레포에 올라가서 **서로의 Claude가** 누가 무엇을 맡았는지 압니다.
`CLAUDE.local.md`는 `.gitignore`에 들어 있어 나만 씁니다. 자주 바뀌는 "지금 하는 일"은 여기에 적습니다.

## 처음 한 번

1. 이 폴더의 `_template.md`를 복사해 `<이름>.md`로 만들고 채웁니다. 예: `junseong.md`
2. 이슈 → 브랜치 → PR로 올립니다. 이게 첫 PR 연습이 됩니다.
3. 레포 맨 위에 `CLAUDE.local.md`를 만듭니다.

```markdown
@.claude/team/junseong.md

## 지금 하는 일
- #12 홈 화면 목업 구현

## 내 Claude에게
- 설명은 짧게, 예시 코드 위주로
```

첫 줄의 `@경로`는 그 파일 내용을 그대로 불러오는 문법입니다.
