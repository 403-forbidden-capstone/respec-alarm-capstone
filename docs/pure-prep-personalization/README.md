# Re:Spec Alarm — 순수준비시간 개인화 작동 원리

웹페이지: [index.html](./index.html)

2026-11-26 기능 설명·합성 기록 E2E 데모. 전체 페이지는 HTML/CSS/JS 단일 파일이며 외부 패키지, 인증, Supabase API 호출, 브라우저 저장, 가짜 기록의 운영 DB 삽입이 없습니다.

## 화면의 내용
- 유효 기록 수 0~15건을 움직여 9건 PROFILE → 10건 MODEL 전환 확인
- 전날 기록, 동의, 연령 검증, 테스트 사용자 allowlist, 설정 변경 후 기록, 모델 서버 정상 여부를 조작
- CatBoost v2 응답은 앞서 실제 ML 서버에서 관측한 입력 baseline 30분 → 결과 25.916분을 설명용으로 **모킹**합니다. 결과를 26분으로 반올림해 계획에 반영합니다.
- 약속 10:00, 이동 20분, 여유 0분, 기본 준비 35분: 9건이면 기상 09:05, 10건이면 09:14. 출발은 09:40 고정
- 모델 장애, 동의 미완료, 불충분한 이력에서는 PROFILE으로 폴백
- UI의 '준비 전 활동 0분' 기본값은 [FastAPI PR #23](https://github.com/403-forbidden-capstone/respec-server/pull/23)의 수정 **제안안**입니다. 운영 적용 완료로 오인하지 않도록 페이지에서도 표시합니다.
- 실험 근거: 해당 PR의 전체 FakeDb / 모킹 E2E CI 1,173/1,173 통과 (확인 시점 2026-11-26). 모델의 실측 정확도를 증명하는 테스트는 아닙니다.

## 열기 및 외부 공유
1. 파일을 내려받아 PC나 모바일 브라우저에서 열면 독립 실행됩니다.
2. 공개 GitHub 저장소의 파일을 HTML로 보여주는 서비스를 이용할 수 있습니다. 예: [raw.githack.com](https://raw.githack.com/). 일부 서비스는 첫 접속 시 보안 확인 화면을 띄울 수 있습니다.
3. 팀의 공식 도메인에서 상시 운영하려면 GitHub Pages 또는 관리되는 정적 호스팅으로 이 단일 파일을 배포하세요. 단, GitHub Pages는 별도 활성화가 필요합니다.
