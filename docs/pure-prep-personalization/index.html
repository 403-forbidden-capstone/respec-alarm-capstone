01 — HOW IT WORKS

기록이 실제 알람이 되기까지

단순히 예측값을 보여주는 기능이 아니라, 약속의 출발·기상 시각을 역산하는 과정입니다.

01

준비 기록 수집

준비 알람에서 시작한 시각과 위치로 확인한 출발 시각의 차이를 저장합니다.

02

기록 유효성 확인

10~240분, 수정 후 기록, 유효 10건 이상, 약속 전날 기록 등 조건을 검사합니다.

03

예측 또는 폴백

동의·연령 검증·허용 계정 조건을 통과하면 모델 호출. 그렇지 않으면 입력값을 사용합니다.

04

알람 시각 역산

약속 − 여유 − 이동 = 출발. 출발 − 순수준비시간 = 준비 시작 시각입니다.

04 — IMPORTANT NOTES

모델 예측과 실제 서비스는 구분합니다.

실제 개발 상태와 이번 데모의 범위를 정확하게 표시했습니다.

모델 학습 타깃

실측 준비시간을 직접 학습한 모델은 아닙니다.

원본 CatBoost v2의 학습 타깃은 survey_start_cluster_proxy입니다. 생활시간조사 대리 타깃이 실제 앱의 준비 시작→출발 기록과 얼마나 일치하는지는 추가 검증이 필요합니다. 10건은 호출 자격 기준이며 성능 보증이 아닙니다.

운영 반영 상태

20분 기본값 제거는 테스트 브랜치 기준입니다.

모델 서빙 및 데모 계정 허용 설정은 적용됐지만, 이 페이지의 미설정 준비 전 활동시간 = 0분 계산은 PR #23에서 검증한 수정안입니다. 실제 운영에서는 해당 PR이 배포되기 전까지 결과가 다를 수 있습니다.
