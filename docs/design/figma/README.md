# 피그마 화면

팀원 피그마(Figma Make) 화면 16개를 PNG로 저장함. 피그마 MCP는 한 달 20회뿐이라 화면 모양은 여기 이미지를 먼저 봄.

- 출처: https://coal-clone-84315963.figma.site (화면 보드 · 화면마다 "열기") — 브라우저로 열어 캡처, MCP 호출 0회
- 피그마 파일: https://www.figma.com/design/VfYr1eedTA2Iq43WewaWII (위 사이트를 10/1에 가져온 사본)
- 캡처: 2026-10-08, 화면 393×852를 3배(1203×2580)로
- 긴 화면은 `-bottom` = 화면 안을 맨 아래까지 내린 모습

## 캡처 주의

- 글꼴: 사이트가 Pretendard를 못 불러와 시스템 글꼴로 찍힘 → 글꼴 · 글자 크기는 `mobile/src/theme` 기준
- 흰 글씨 카드: H01 다음 알람 · G02 그룹 공유 범위 · P02 맨 위 · P03 다음 알람 · P04 완료 카드는 배경 없이 흰 글씨라 비어 보임. 사이트에서도 같게 보임
- 오른쪽 위 작은 번호(`H01 · 홈` 등)는 사이트 표시라 앱엔 안 넣음

사이트가 바뀌면 다시 캡처해서 덮어씀.
