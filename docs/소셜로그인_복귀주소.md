# 소셜 로그인 후 앱 복귀 주소

2026년 11월 2일, 안드로이드 개발용 앱에서 카카오 로그인 뒤 `localhost:3000` 연결 거부 화면이 나왔다. 앱의 실제 요청 주소는 `respecalarm://auth/callback`이었고, 실서버 인증 설정의 복귀 주소 허용 목록에는 이 주소가 없었다. 기본 사이트 주소는 `http://localhost:3000`이었다.

인증 서버에서 기존 웹 주소를 유지하고 `respecalarm://auth/callback`을 허용 목록에 추가했다. 다른 서버 설정은 변경하지 않았다. 변경 뒤 사용자는 앱 로그인이 잘 된다고 확인했다. 카카오와 구글 각각의 성공 여부는 구분해 확인하지 못했다. 기본 사이트 주소가 로컬호스트인 문제는 앱 주소 추가와 별개로 웹 운영 주소와 인증 흐름을 확인한 뒤 결정한다.

`supabase/config.toml`은 로컬 개발용 값과 실서버 값이 다르다. 파일 전체를 실서버에 그대로 적용하면 인증 복귀 주소를 포함한 기존 설정이 바뀔 수 있다. 실서버 설정 변경 전에는 대상 프로젝트와 `supabase config diff`의 선언된 변경 항목을 확인하고, 웹·앱의 기존 주소를 보존한다. 다른 인증 제공자나 비밀값은 이 문서에 기록하지 않는다.
