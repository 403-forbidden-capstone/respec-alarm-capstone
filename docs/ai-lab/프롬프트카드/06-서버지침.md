# 서버 지침 (⑥) — 지금까지 배운, 서버가 맡아야 할 일

> 10/10 E0 · E1 · E2 결과까지. 근거 = [실험정리.md](../실험정리.md) E0 · E1 · E2, [spec/e0.md](../spec/e0.md) · [spec/e1.md](../spec/e1.md) · [spec/e2.md](../spec/e2.md), 라운드 1 [spec/t1-round1.md](../spec/t1-round1.md), 실패 처리표 [spec/runtime-failure-handling.md](../spec/runtime-failure-handling.md).
> AI는 말만 하고 숫자 · 저장 · 알람 · 위기 판단 · 마무리 조건은 서버가 쥔다는 구조는 그대로. 아래 규칙의 숫자는 모두 Claude Haiku 5.5에서 본 것이고 **Gemini에서는 확인 안 됨**.
> 상태: **검증** = 이 실험에서 켜고 돌려 봄 · **구현** = 코드로 넣고 단위 시험을 통과했으나 대화로는 안 돌려 봄 · **부분** = 근거가 있으나 켠 채로 돌려 보진 않음 · **미검증** = 제안

## 5. 기록 (분석용)

- 호출마다 남길 것: 서버가 만든 화면(`확인할 기록` 줄 포함, 시각 말로 여부) · 프롬프트 id · 옵션(`view_opts`: `confirmFacts` · `spokenTimes`) · 출력 · 서버 처리 · 규칙 걸림 · 막은 문장.
