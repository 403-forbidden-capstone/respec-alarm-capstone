# AI 실험실 기록

앱의 AI 역할(대화 답 · 추출 · 일기 · 코칭 · 추천 비서)에 넣을 프롬프트를 가상 사용자로 실험한 기록. ai-lab(로컬 실험실)에서 `npm run share`로 복사한 것이라 여기서 직접 고치지 않음.

진행: v3 · E0 ~ E5 · 최종 시험 끝 · 다음 피드백 루프

## 알아 둘 것

- 실험 모델 = Claude Haiku 5.5 (API 크레딧 기간 실험용). 앱에 넣을 모델은 Gemini(gemini-3.8-flash 가정) — Gemini에서 같은지는 아직 확인 안 함.
- 사용자 말 = 안드로이드 기본 음성 인식 결과를 흉내 낸 글. 실제 녹음 아님.
- 가상 사용자 · 14일 기록은 만든 데이터. 개발용 8명만 공개, 시험용 4명의 사람 · 대화는 비공개 (최종 시험은 숫자 표만).
- 실행 기록 원본(runs/, 약 170MB)은 올리지 않음 — 문서 안 `runs/...` 같은 글자는 로컬 실험실에만 있는 파일. 대화는 /lab 화면에서 볼 수 있음.
