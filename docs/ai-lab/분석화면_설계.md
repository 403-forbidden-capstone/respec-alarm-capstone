# 분석 화면 설계 — 배포 사이트 `/lab`

> 10/10 초안. 목표: 보고서를 읽다가 궁금한 걸 바로 열어 보게 — 기능별 · 실험별 · 사람별 · 대화별 · 프롬프트 버전별로 자유롭게.
> 비유: 앰플리튜드에서 실제 사용자 데이터를 보듯, 가상 유저 12명의 기록 · 대화 · AI 판단을 봄.

## 1. 어디에 · 어떻게

| 항목 | 내용 |
|---|---|
| 주소 | `respec-alarm-capstone.vmgfh878.workers.dev/lab` (개발 보드 `/board`와 같은 방식의 정적 화면) |
| 파일 | 배포 레포 `mobile/public/lab/index.html` + `mobile/public/lab/data/*.json` |
| 데이터 | 실험실(`ai-lab/runs`)의 결과를 화면용으로 바꾼 묶음. 대화는 하나씩 필요할 때만 불러옴 |
| 갱신 | 실험실에서 묶음 만들기 → 배포 레포로 복사 → PR → 머지하면 배포. 실험 하나 끝날 때마다 (대략 4 ~ 5번) |
| 로컬판 | 같은 화면을 실험실에서 `npm run dash`로도 띄움 — 실험 중엔 이걸로 바로바로 봄 |
| 크기 | 대화 약 600건 + 프롬프트 · 사람 · 실험 → 압축 전 약 10 ~ 20MB 예상. 파일 하나 25MB 제한 안 |

**조심할 것**
- **공개 주소** — 주소를 알면 누구나 봄. 데이터는 전부 가짜라 개인정보 문제는 없지만 프롬프트 · 대화가 다 보임. 막고 싶으면 Cloudflare Access(로그인한 사람만)를 사용자가 대시보드에서 켜면 됨 (무료, 50명까지)
- **시험용 대화는 최종 시험이 끝날 때까지 안 넣음** — 미리 보면 시험용에 맞춰 프롬프트를 고치게 돼서 마지막 확인이 의미 없어짐
- **AI 생각** — 지금까지 실행은 생각 내용을 저장 안 했음 (생각에 쓴 토큰 수만 있음). v3 실험부터 저장하고, 예전 대화엔 "기록 없음"으로 표시

## 2. 전체 구조

```
┌───────────────────────────────────────────────────────────────────────────┐
│ Re:Spec AI 실험실    홈 · 기능 · 실험 · 사람 · 대화 · 프롬프트 · 용어   [필터 ▾] │
├───────────────────────────────────────────────────────────────────────────┤
│ 필터: 기능 [대화 ▾] 실험 [E1 ▾] 버전 [전부 ▾] 사람 [전부 ▾] 상황 [전부 ▾] 결과 [문제 있음 ▾] │
└───────────────────────────────────────────────────────────────────────────┘
```

| 메뉴 | 한 줄 설명 | 들어가면 |
|---|---|---|
| 홈 | 실험 전체 한눈에 | 진행 단계 · 크레딧 · 실험별 결론 카드 |
| 기능 | 앱 지점별 (① 받아쓰기 정리 · ② 추출 · ③ 대화 답 · ④ 일기 · 코칭 · ⑤ 추천 비서) | 그 기능의 지금 프롬프트 · 버전 역사 · 관련 실험 · 대표 대화 |
| 실험 | E0 ~ E4 + 예전 라운드 | 무엇을 비교했고, 결과가 어땠고, 달라진 대화 |
| 사람 | 가상 유저 12명 | 가정 카드 · 날짜별 타임라인 · AI가 맞힌 것 / 틀린 것 |
| 대화 | 모든 대화 | 턴마다 받아쓰기 → 정리 → 추출 → 서버 → AI 생각 → 답 · 검사 |
| 프롬프트 | 모든 버전 | 전문 · 바뀐 줄 · 이 버전을 쓴 실험과 결과 |
| 용어 | 화면에 나오는 말 풀이 | "확인 필요", "숨은 사실", "규칙 어김" … |

**공통 필터** — 모든 목록 화면 위에 같은 필터 바. 고른 값은 주소에 남아서 링크를 그대로 공유하면 같은 화면이 열림
- 기능 · 실험 · 프롬프트 버전 · 사람 · 말투 · 상황 유형(늦잠 · 새 일정 · 기록 정정 · 위험한 말 등 21종) · 결과(문제 없음 / 있음 · 문제 종류) · 자기 전 / 기상 후

### 3.5 대화 상세 (턴 하나하나)

맨 위: 상황 · 사람 요약 · 숨은 사실 체크리스트(전달됐나) · 설문 점수 · 이 대화가 나온 실험 · 판
가운데: 턴 카드. 오른쪽 위 [나란히 보기]를 누르면 같은 상황의 다른 판 대화를 옆에 놓음

```
┌ 사용자 2턴 ──────────────────────────────────────────────────────┐
│ 하려던 말   앞에 두 개는 맞고 8시 10분은 아니에요. 편의점 잠깐 간 거예요.  │
│ 받아쓰기    앞에 두 개는 맞고 여덟 시 십 분은 아니에요 편의점 잠깐 간 거예요 │
│ ① 정리      앞의 두 개는 맞고, 8시 10분 출발은 아니에요. 편의점에 잠깐 …   │
│ ② 추출      기록 정정: 출발 20:10 → 아님                                │
│ 서버        출발 20:10 지움 · 저장됨                                    │
│ 검수자      숨은 사실 h2 (감지 오류 정정) 전달됨 ✓                       │
├ AI 3턴 ──────────────────────────────────────────────────────────┤
│ ③ 답        편의점에 잠깐 다녀온 거였군요. 오늘 하루는 어땠어요?          │
│ 검사        규칙 ✓ · 숫자 ✓ · 물음 1개 ✓ · 길이 27자 ✓                   │
│ ▸ AI가 받은 화면 (펼치기)                                              │
│ ▸ AI 생각 요약 (펼치기)  사용자가 20:10 출발을 부정 → 서버가 지움 …       │
│ ▸ 판정기 메모 · 비용 $0.0003 · 2.4초                                   │
└───────────────────────────────────────────────────────────────┘
```
- 문제가 있는 턴은 빨간 줄 + 어떤 규칙을 어겼는지 한 줄 ("저장 안 했는데 '고쳐 둘게요'라고 약속")
- 추출 JSON은 사람 말로 풀어서 보여 주고 [원본 JSON]으로 펼침

```

버전 상세
```

### 3.8 용어

| 화면 말 | 뜻 |
|---|---|
| 숨은 사실 | 가상 유저만 아는 오늘의 진짜 사정. AI가 대화로 알아내야 함 |
| 확인 필요 | 서버가 "저장할까요?"를 물어야 하는 것 (일정 · 시각 · 알람 바꾸기) |
| 규칙 어김 | 한 번에 두 개 묻기, 서버가 안 한 저장 약속, 위험하지 않은데 109 등 — 코드가 셈 |
| 판 (A · B · C) | 같은 상황에서 프롬프트나 서버 설정만 바꿔 다시 돌린 것 |
| 개발용 / 시험용 | 프롬프트를 고칠 때 보는 사람 8명 / 마지막에 한 번만 확인하는 처음 보는 사람 4명 |
