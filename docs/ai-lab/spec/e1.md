| 시각 | 말 |
|---|---|
| 00:00~00:59 | 밤 12시 · 밤 12시 30분 |
| 01:00~05:59 | 새벽 1시 5분 |

다음에 시험해 볼 서버 쪽 개선 (이번엔 미검증):
1. 서버 고르기: **기상 기록은 늘 목록에 넣기** (출발 · 도착 2개 + 기상 1개). 근거: 목록에 든 기상 36/36, 빠진 기상 0/10. 이 규칙이면 못 고친 17개 중 최대 10개를 더 살릴 수 있음.
2. 첫 마디(확인할 기록 읽기)를 **서버가 만든 문장**으로: AI가 목록을 안 따르는 20%(5개 기록)를 없앰. 라운드 1에서도 T1은 템플릿을 못 이겼음.
3. 틀렸다고 한 기록(CORRECTED · DENIED)은 모두 **'저장됨' 줄**을 줌 (DENIED는 지금 줄이 없음) → "빼 둘게요" 같은 약속이 사라질 것.
4. 알람이 바뀌면 서버가 **말할 알람을 하나(기상)로 줄여** 넘기거나 문장 한 줄을 만들어 줌.
5. 서버 질문이 남아 있는데 AI가 마무리하려 하면 서버가 막고 질문을 챙김 (B 4/46 놓침).
6. 검사기에 '빼 둘게요 · 지울게요 · 삭제할게요 · 알고 있을게요'를 약속으로 추가.

사용자가 정할 것 (보고에 따로 적음): 위 서버 개선 중 먼저 시험할 것 · 알람 시각을 AI가 몇 개까지 말하게 할지 · +0.4턴을 받아들일지.

## 7. 아직 모르는 것 · 한계

- **Gemini에서는 하나도 확인 안 됨.** 특히 목록 따르기(82%) · 때 표시 말투 · 금지 예가 말을 부르는 일 · 80자 · 한 번에 물음 1개.
