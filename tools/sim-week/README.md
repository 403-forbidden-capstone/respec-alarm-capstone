# sim-week — 가상 유저 일주일 시험 하네스 (기능 모드)

가상 유저 p01~p08(dev)이 앱으로 일주일을 살아 보는 시험 도구입니다. **이번 판은 기능 모드: 모델 호출 · 네트워크 호출 · API 키가 없습니다.**
밤 대화는 글 없이 결정으로 흉내 내고(서버 순수 함수 `turn-core` · `context-core`를 그대로 부름), 아침 하루는 진짜 일어난 일 → 위치 신호 → L2 판정으로 앱 기록을 만듭니다.
앱 · 서버 코드는 한 줄도 안 고치고 `bridge.ts`(별칭 · 확장자 해석 · supabase/user 껍데기)로만 불러 씁니다.

## 실행

```
node tools/sim-week/run.ts --personas p01,p02 --days 1 --fake [--app-root <경로>] [--report <경로>] [--seed 글자] [--budget 달러] [--code-label 글자]
node --test "tools/sim-week/**/*.test.ts"
```

- `--days N` 또는 `1..N` (1일째부터 N일까지, 학습이 이월되므로 중간부터는 안 돌림). `--fake`가 기본이고 지금은 이것만. `--live`는 "기능 모드만 지원" 오류로 거절.
- `--app-root`(또는 env `SIM_APP_ROOT`): 아직 PR인 코드를 합친 임시 worktree를 가리켜 그 코드로 돌림. 안 주면 이 레포(main).
- `--budget`은 받아서 보고서에 표시만 합니다(실호출 모드 자리 표시).
- 보고서는 `tools/sim-week/runs/`(레포에 안 올림)에 마크다운으로 씁니다. 사람 × 날짜 줄마다 PR 코드(앱 코드가 origin/main과 같으면 `main@커밋7자리`) · 쓴 씨앗 · 상황 이름, 밤 대화, 위치 조정 표, 기능 확인 표, 질문 예산, 버그 후보.

## 시험 기준 (헤드 10/30)

1. 씨앗 고정(사람 id + 날짜). 위치 조정 때는 같은 씨앗, 값만 바꿈.
2. 아침 행동 = 인물 카드 값 + 하루 흔들림. 미루기 횟수 = 0..snooze_tendency 중 하나(최대 3번, 미루기 시간은 앱 기본, D3). 늦잠(첫 알람을 놓쳐 미루기 3번 다 쓰고 +15분) = chronotype LATE 또는 새벽 2시 이후 취침 인물만 주 1번, 나머지는 주 0번. 준비 = prep_minutes × 0.9~1.2 + 그 요일 recurring_reasons 분. 이동 = travel_minutes × 0.9~1.25, 주 1~2일은 비 오는 날로 대중교통 +15%.
3. 위치 상황 6종: 한 주에 6종 모두 최소 1번, 한 사람 하루 최대 1개, 나머지 날은 깔끔한 날. 조깅은 아침형 인물, 나머지는 고루.
4. 밤 대화 카드 수락: cooperation HIGH 90% · MID 70% · LOW 40%, 정정은 correction_tendency대로. AI 질문 수 · 원탭이 필요했던 수는 매일 셈(하루 1 · 주 3 — D104 · 7.15 기준 위반이면 버그 후보로 표시).
5. 지각 경계 · 반경 · 감지 지연은 L2 코드 값을 그대로 쓰고, 위치 조정 표에서만 바꿈.
6. 결과 표에는 사람 × 날짜 줄마다 "PR 코드" · 쓴 씨앗 · 상황 이름.

하네스가 혼자 정한 것은 `DECISIONS.md`, L1 입력이 알람을 바꾸는 방식과 L2에서 못 부른 것은 `docs.md`.
