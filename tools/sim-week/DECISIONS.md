# 하네스 판단 기록 (지시서에 기준이 없어 하네스 작성자가 정한 것)

형식: 무엇을 · 왜 그렇게 · 대안. 헤드가 나중에 확인.

| # | 무엇을 | 왜 그렇게 | 대안 |
|---|---|---|---|
| 1 | 인물 성향 → 기상: 미루기 수 = 정규(평균 `snooze_tendency`, sd 0.7), 월요일 +1(미루기 2 이상), 강도 강(2)이면 50%로 −1 | 지시서에 "미루기 횟수 snooze_tendency"만 있음. 강한 알람이 덜 미루게 한다는 가정 | 강도와 무관하게 고정 |
| 2 | 늦잠(알람을 놓침) 확률: LATE 0.25 · NORMAL 0.08 · EARLY 0.03, 강도 강이면 절반, 놓친 분 15~45 | chronotype만 있고 확률 기준이 없음 | ai-lab timelines의 oversleep_minutes 분포로 맞춤 |
| 3 | 기상 습관(누워서 폰 · 다시 잠 · 알람 전 깸) · 첫 잠금 해제 지연 · 자동 확인률은 ai-lab v3 `flow.wake`를 그대로 씀 | 이미 인물 카드에 있는 값 | 기본 필드만 쓰기 |
| 4 | 준비 = prep_minutes + 요일 사유(recurring_reasons) + N(0, 4.5분). 출발 알람보다 늦으면 5분까지 서두르고, 8분 넘게 늦으면 skip_when_late 사유(머리 감기)를 건너뜀 | 지시서의 "prep ± 흔들림, recurring_reasons extra_minutes" 구현. 서두름 규칙은 v3 `skip_when_late` 뜻 | 서두름 없음 |
| 5 | 준비가 일찍 끝나도 출발 알람 −2분까지 기다렸다 나감 | 출발 알람이 "나갈 때"를 정하게 해 알람 효과를 보려고 | 준비 끝나면 바로 출발 |
| 6 | 이동 = 평소 이동(travel_minutes) + 요일 추가 + N(0, sd) + v3 사고(확률). 지각 진실 기준은 앱 규칙과 같은 +5분 | 지시서 "travel ± 흔들림". 앱 규칙과 같은 기준이라야 오판을 셈 | 약속 시각 초과를 지각으로 |
| 7 | 카카오 못 부름: 장소 좌표를 집에서 "카카오 대역 분(v3 api_estimate_min)"만큼 떨어진 곳에 시험이 만듦. 카카오 대역이 켜지면 그 분을 그대로 돌려주고, 꺼지면 L1 규칙(실측 3건↑ 중앙값 → 좌표 근사값) | 지시서 | 평소 이동을 카카오 값으로 |
| 8 | 위치 상황 6종 배정표(persona.ts `PLAN`): 한 주에 6종이 모두 나오도록 사람 × 날에 손으로 흩뿌림. NEAR는 "20:00 집앞 스터디카페" 일정을 시험이 추가(표에 synthetic 표시) | 지시서에 어느 날에 넣을지 기준 없음 | 난수 배정 |
| 9 | 이동 속도 모델: 걷기 70m/분, 대중교통 처음 700m는 걷고 이후 600m/분, 자차 처음 70m 걷고 이후 700m/분. 반경 통과 시각 = 이 모델로 계산 | 반경(150·200·300m)이 신호 시각에 미치는 영향을 보이려고 | 거리 무시하고 지연만 |
| 10 | CAMPUS: 학교 대표 좌표에 300m 반경, 실제 건물은 대표점에서 450m → 반경 진입이 건물 도착보다 약 10분 이름 | D68 "대표 좌표" 경고를 재현 | 건물까지 거리 다른 값 |
| 11 | 감지 지연: 기본은 N(2.6, 1.6)분을 1~6으로 자름, 조정 실행은 고정 1·3·6 | 핵심선별 A "보통 2분 이내 · 최대 6분" | 균등 1~6 |
| 12 | 지각 경계 +11분: 위치 도착이 약속+11분을 넘을 때만 지각, 보류 없음. +5분은 실제 `judgeArrival`(−2~+5분 보류) | constants.ts `LOCATION_HOLD_AFTER_MINUTES` + 설계 메모 #240 설명 | #240 코드가 있으면 그 코드(PR 코드 기준 실행) |
| 13 | 앱이 깨는 때: 새 신호가 올 때, 그리고 밤 21:00(자기 전 대화 시작) `resolvePending` | "받는 쪽 A는 타이머가 없음" 주석 | 알람마다 깨기 |
| 14 | 원탭 응답률 = v3 `conversation.tap_prob`. 응답은 BUTTON 출처로 위치 값을 덮음(`decideWrite`) | 인물 카드 값 | 늘 응답 |
| 15 | 오판 이름: DEPART_FALSE / DEPART_MISSED / ARRIVE_EARLY(5분↑ 이름) / ARRIVE_MISSED / LATE_MISSED / LATE_FALSE. 원탭 필요: 출발 없음·틀림, 도착 없음, 도착 보류, 기상 자동 확인 실패 | "오판 수 · 원탭이 필요했던 수" 정의가 없음 | — |
| 16 | 앞 약속 뒤 150분 미만이면 집에 안 가고 바로 이동(앱은 집 출발로 앎) | 출발지 가정 한계를 드러내려고 | 늘 집 경유 |
| 17 | 처음 앱이 아는 일정은 없음: 일주일 전체를 대화로 받음 (반복 수업도 요일마다 다른 항목이라 한 주 안에서는 같은 약속이 되풀이되지 않음). 가입 때 준비 시간 기본값 = 공통 P80 50분(`DEFAULT_COMMON_P80`), 여유 = 인물 buffer_minutes | 지시서 "기록 0~4건은 가입 때 기본값" | 시간표를 가입 때 등록 |
