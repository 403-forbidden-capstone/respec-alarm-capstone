# 16장 대본 단계표 (S3)

출처: `친구_논리설계.md` 16장(확정 11/8). 사람이 누르는 대본은 A · B, **C 단계(12~14 · 19 · 23 · 24 · 29~34)는 자동**(`node run.mjs`가 C로 로그인해 돌림). 자동 시험은 A · B 단계도 같은 일을 DB에 해서 확인하고, 화면 글자 · 버튼 모양은 보지 않습니다.

기준 환경 = 로컬 Supabase. 대본의 시드 상태(친구 2 · 요청 1 · 그룹 1 · 기상 공유 동의 끔)와 지금 시드(친구 3 · 요청 1 · 그룹원 4 · 동의 켬 일부)는 다름 → 자동 시험은 A · B · C끼리의 친구 · 권한을 비우고 시작해 끝나면 되돌림.
